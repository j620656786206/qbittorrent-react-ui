### F19｜shadcn 的變數各對到哪個品牌角色

- **決定**：照下表對。深色模式一律用同名的 `-dark` 值。

| shadcn 變數 | 品牌角色 |
|---|---|
| `background` | `surface-page` |
| `foreground` | `text` |
| `card`、`popover` | `surface` |
| `card-foreground`、`popover-foreground` | `text` |
| `primary` | 品牌的 `accent` |
| `primary-foreground` | 品牌的 `accent-foreground` |
| `secondary`、`muted` | `surface-muted` |
| `secondary-foreground` | `text` |
| `muted-foreground` | `text-muted` |
| shadcn 的 `accent`（選單 hover、Skeleton 底） | `surface-muted` |
| shadcn 的 `accent-foreground` | `text` |
| `destructive` | `delete`（字用 `delete-foreground`） |
| `border`、`input` | `border` |
| `ring` | 品牌的 `accent` |

- 撞名的處理：品牌的 `accent` 在程式裡接到 shadcn 的 `--primary`。shadcn 的 `--accent` 接 `surface-muted`。規格裡提到「accent」一律指品牌的。
- 結果：選單 hover 和骨架是淡灰底，不會變整塊黑。Dialog、選單、底部面板在深色模式是 `surface-dark`，跟卡片同色。
- 對話框後面的遮罩沿用 shadcn 預設，不另外定。
- **理由**：品牌角色跟 shadcn 的變數幾乎一對一，只有 `accent` 撞名，照「意思」對就好（DESIGN.md Colors：顏色照角色分）。
- **改哪裡**：`DESIGN.md` frontmatter 開頭那句「沒列的 shadcn token 先沿用」換成這張表，放在 Colors 的「其他角色」後面。

### F34｜數字寫法

**建議 Alex 看一下：日期寫法整個 App 都會看到（#119 留到這題定）。**

- **決定**：加一節「數字寫法」。
  - **千分位**：有。「3,631」。
  - **大小**：單位照 qBittorrent（1024 進位），寫 MB、GB、TB。滿 1,024 GB 換 TB。最多一位小數，「.0」不寫：「85 GB」「301.2 GB」「22.1 TB」。
  - **速度**：KB/s 寫整數，滿 1,024 KB/s 換 MB/s。MB/s 小於 10 寫兩位小數（「6.21 MB/s」），10 以上寫一位（「32.7 MB/s」）。
  - **速度是 0**：卡片和列的第二行不寫速度。全域速度寫「↓ 0 KB/s」。當大數字時寫「0」，用 `text-muted`。
  - **剩餘時間**：「剩不到 1 分」「剩 34 分」「剩 3 小時 12 分」「剩 2 天 5 小時」。下載中但速度是 0、或算不出來：「剩餘時間不明」。
  - **日期（哪一天發生的：加入、完成）**：今天「今天 09:12」；昨天「昨天 21:40」；今年「11/05」；往年「2025/07/18」。24 小時制。完成欄第二行就是「今天 09:12 下載好了」「11/05 下載好了」（#119）。
  - **離現在多久（最後有人抓、最後更新）**：「剛剛」「20 秒前」「5 分前」「3 小時前」「3 天前」。
  - **長度（做種時間、活動時間）**：「41 天」。不到 1 天「5 小時」，不到 1 小時「12 分」。超過一年也寫天數「412 天」。
  - **分享率**：兩位小數「3.12」。無限大寫「∞」。1 以上用 `good`。
  - **百分比**：整數「87%」，無條件捨去，沒做完不會寫 100%。
  - **沒有值**：寫「沒有」，用 `text-muted`。例如還沒完成的完成時間。
- **列表右邊的大數字**：靠右對齊，等寬數字，不固定欄寬，最寬 160px。
  - 數字類用 `row-value`（18px 粗體）。
  - 文字類（分類、路徑、Hash、註解）用 `body` 13px、`text-muted`，超過 160px 切掉。路徑從前面切（見 F78），Hash 只寫前 8 碼（用 `path` 等寬字）。
